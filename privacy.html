Privacy Policy

hermes-mail-filter is a personal, single-user tool. It runs only on the owner's own computer and accesses only the owner's own Gmail account.

  • It uses the Gmail API only to read message metadata and to move messages between the Inbox and one label.
  • Credentials and data are stored only on the owner's computer. Nothing is sent to any third-party server.
  • No data is sold, shared, or used for advertising.
